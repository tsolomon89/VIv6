# Standard Definitions

> **Role**: These are the "Standard Library" of definitions provided by Oblio (Tier 1).
> **Usage**: The Simulator and Analytics engines rely on these specific Slugs.

## 1. Standard Activity Types
These verbs are hardcoded into the `Activity.type` enum or defined as `ActivityDef` records in Tier 1.

| Slug | Description | Required Metadata |
| :--- | :--- | :--- |
| `page_view` | User loaded a page. | `url`, `referrer`, `userAgent` |
| `form_submit` | User submitted a form. | `formId`, `formData` |
| `click` | User clicked a tracked element. | `elementId`, `targetUrl` |
| `login` | User authenticated. | `method` ('email', 'google') |
| `email_open` | Contact opened an email. | `emailId`, `campaignId` |
| `conversion` | A goal was met. | `value`, `currency` |
| `churn` | A customer left. | `reason` |

## 2. Functional Activity Archetypes
The Game Engine generalizes all operations into these four types (The "Kinetic Taxonomy").

| Archetype | UI Name | Definition | Activation Trigger |
| :--- | :--- | :--- | :--- |
| **Data** | Research | Create/Update Record | Field `NULL` -> `NOT NULL` |
| **Asset** | Creative | Create Content | Status `Draft` -> `Active` |
| **Engagement** | Outreach | Transfer Asset (Email/Call) | Outbound (Sent) or Inbound (Clicked) |
| **Admin** | Approval | Governance/Review | Status `Pending` -> `Approved` |

## 3. Activity Physics
The system enforces rigorous "Physics" on every Activity Record.

### The Three Durations (Time = Cost)
1. **Default Duration**: Theoretical time (e.g., 5 min). Used for Planning.
2. **Baseline Duration**: Historical average. Used for Forecasting.
3. **Actual Duration**: Measured scalar (Sidebar Open -> Close). Used for Billing/CAC.

### Qualifiers (Transmission)
- **Definition**: Boolean conditions required to "Win" an activity.
- **Rule**: `ActivityResult = Won` IFF `All(Qualifiers) == True`.

## 4. Opportunity Levels (The Pipeline)
"Opportunity Type" represents the **Level of Qualification** in the customer journey.

| Level | Slug | Name | Qualification Goal |
| :--- | :--- | :--- | :--- |
| **0** | `opp_mql` | Marketing Qualified | Match Persona + Opt-in (e.g. Form Fill) |
| **1** | `opp_sql` | Sales Qualified | Engagement confirmed (e.g. Call Booked) |
| **2** | `opp_ftp` | First Time Purchase | Contract Signed / Payment Received |
| **3** | `opp_rtp` | Retention Purchase | Renewal / Upsell / Expansion |

> **Transition Logic**: "Winning" an `opp_mql` (Goal Met) automatically creates an `opp_sql`.
