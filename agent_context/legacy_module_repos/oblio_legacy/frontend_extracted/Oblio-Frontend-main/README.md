# Oblio's Frontend, Made With ❤️ Using Flutter

This is the client application project for Oblio. It's built with Google's Dart programming language and the flutter framework. It's also integrated with Firebase services: authentication, hosting, storage, and Firestore DB.

![image](https://user-images.githubusercontent.com/54673205/164709770-4b1c27ea-7993-430d-9d19-aadbc9ba7518.png)


## Getting Started

### Note: If you don't have Flutter installed on your system, follow the instructions on Google's documentation:
https://docs.flutter.dev/get-started/install

Clone this repository before continuing!

```console
bestdv@oblio:~$ cd Oblio-Frontend
bestdv@oblio:~$ flutter pub get
bestdv@oblio:~$ flutter run
```
