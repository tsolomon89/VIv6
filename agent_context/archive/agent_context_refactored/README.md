## The Mission

**Problem**: Managing multiple brands with consistent quality is combinatorially impossible when building pages manually.
**Solution**: **Victory Initiative is a programmatic website generator.** It turns Entity Definitions into complete websites.
*   You declare **what exists** (Entities).
*   The system **derives** the pages, routes, and navigation.

## Agent Guidelines (The Rules)

### 1. Invariants (Never Violate)
*   **Slug is Global**: Uniqueness is enforced across the entire account namespace, not just per-type.
*   **No Free Text**: All user inputs must map to `DimensionValue` selections.
*   **URL = Attribution**: The URL path explicitly encodes the targeting context.
*   **Structs for UI, Records for DB**: Respect the `ui-data-binding.md` architecture.

### 2. Implementation Style
*   **Do**: Use "Core Functions" (`src/core/*`) for all logic.
*   **Do**: Use Semantic Tokens (not raw Tailwind) for styling.
*   **Don't**: Build separate "pages" manually. Declare Entities, let the engine derive the pages.
*   **Don't**: Hardcode section types. Derive them from Bindings.

### 3. Modifying This Corpus
*   If you change a Rule, update `glossary.md`.
*   If you add a Module, update `manifest.yaml`.
*   If you make an architectural decision, add an ADR in `decisions/`.
